## Lab Questions

### In plain English describe the function and use of a multiplexer.
A multiplexer acts like a switch that is used to funnel a specific output
 from multiple inputs based upon the sequence of bits of the switch. 

### In plain English describe the function and use of a demultiplexer.
Takes one input and routes it to various outputs based on the bit value of the switch.

### What other uses might these circuits have? (Think Shannon’s)
Can be used to create and represent arbituary or abstract combinitorial logic, that would otherwise be more difficult
 to represent with logic gates. Also the HVAC example where you want airflow routed to specific parts of a house.
